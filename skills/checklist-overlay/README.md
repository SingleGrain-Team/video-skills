# checklist-overlay

A motion graphic that plays a screen recording in a large frame beside a checklist. Each item ticks off at the exact moment its step happens in the recording, and the film ends with every item checked for a short hold. Includes a small generator (`scripts/create.mjs`) that turns a JSON of steps plus a recording into a HyperFrames composition.

## Install

```bash
npx skills add SingleGrain-Team/video-skills@checklist-overlay
```
