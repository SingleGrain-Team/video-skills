# device-launch-film

Puts a product's real screen on a CSS-built laptop in a dark studio, scrolls it, zooms into the interface for one key action, and resolves to the logo lockup. About 18 seconds, 1920x1080, rendered with HyperFrames. No 3D model or generation model.

Install:

```bash
npx skills add SingleGrain-Team/video-skills@device-launch-film
```

Contents: `SKILL.md` (inputs, workflow, rules, validation) and `template/index.html` (a ready, config-driven composition).
