# title-takeover

A 5-6 second motion graphic: an oversized condensed headline punches in behind a presenter (a background-removed cutout is layered on top of the lettering), a hard cut removes the presenter while the headline holds the exact same size and position, and a short supporting line appears for a reading hold.

Built on HyperFrames. Inputs: presenter clip, 2-4 word headline, supporting line, palette. Output: 1920x1080 H.264 MP4 plus the editable project. See `SKILL.md` for the workflow, timing rules and validation; `template/` has the composition.

## Install

```bash
npx skills add SingleGrain-Team/video-skills@title-takeover
```
