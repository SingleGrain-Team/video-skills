# liquid-logo-reveal

A 7-second logo sting: your mark rides inside a refracting liquid bead, the bead ruptures, and the lockup is left crisp on screen (MP4 + editable HyperFrames project).

Install: `npx skills add SingleGrain-Team/video-skills@liquid-logo-reveal`

Based on: `liquid-brand-refraction` in https://github.com/heygen-com/hyperframes-launches (Apache-2.0, © HeyGen, Inc.). Code structure and timing were adapted; none of HeyGen's media, logos or fonts are included.
