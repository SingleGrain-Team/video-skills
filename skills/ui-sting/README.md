# ui-sting

A 10-14 second product sting of UI moments (entry screen, counting metric, nav, click, menu, endcard) cut so every seam carries motion forward, rendered with HyperFrames.

Install: `npx skills add SingleGrain-Team/video-skills@ui-sting`

Based on: `01-ui-sting` from HeyGen's hyperframes-launches (https://github.com/heygen-com/hyperframes-launches), Apache-2.0, © HeyGen, Inc. Code structure and timing technique were adapted; none of its media, logos or fonts are included.
